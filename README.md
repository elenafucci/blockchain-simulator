# Simulatore (tesina di crittografia)

Repository di supporto per la tesina: semplice simulatore usato per esperimenti e plot.

## Struttura
- `files/`: codice sorgente principale
- `output/`: dati di output (log, risultati)

## Requisiti
- Python 3.8+

## Installazione
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
``` 

Oppure, se usi `pyproject.toml`:
```bash
pip install -e .
```
